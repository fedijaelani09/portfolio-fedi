ASAT Praktik TJKT 2026 — Infrastructure Network Enterprise

Project ini merupakan simulasi sebagai Network Administrator pada PT TKJ Network Solution dengan fokus pada perancangan dan implementasi infrastruktur jaringan skala enterprise menggunakan teknologi modern.
Project Overview
Merancang dan mengimplementasikan infrastruktur jaringan lengkap menggunakan MikroTik, VLAN, Hotspot, Firewall, AWS Cloud, MariaDB, Nginx, dan WordPress.
Key Achievements
• Merancang topologi jaringan perusahaan
• Implementasi VLAN 101 dan VLAN 102
• Membangun sistem hotspot autentikasi
• Konfigurasi firewall dan NAT
• Deploy server AWS EC2
• Konfigurasi MariaDB database
• Instalasi WordPress CMS
• Server hardening menggunakan UFW
Technologies Used
MikroTik • AWS EC2 • Debian • Ubuntu • Nginx • MariaDB • WordPress • UFW • VLAN
VLAN & Network Segmentation
Segmentasi jaringan untuk divisi HRD, Marketing, Hotspot, dan NOC menggunakan MikroTik RouterOS dan RB260GS.

Features:
• VLAN 101 (HRD)
• VLAN 102 (Marketing)
• Inter-VLAN Routing
• DHCP Server
• Network Isolation
AWS Cloud Deployment
Deployment website pada AWS EC2 dengan Elastic IP, Security Group, DNS lokal, dan Nginx web server.

Features:
• Cloud Hosting Architecture
• Elastic IP Configuration
• Security Group Setup
• SSH Management
• Public Website Access
MikroTik Hotspot System
Sistem hotspot dengan captive portal dan user authentication untuk kontrol akses jaringan.

Features:
• Captive Portal Login
• User Authentication System
• User Profile Management
• WiFi Access Control
Linux Server Administration
Manajemen server Linux berbasis Debian dan Ubuntu untuk kebutuhan infrastruktur IT.

Scope:
• Nginx Web Server
• Apache Web Server
• MariaDB Database
• DNS Server
• SSH Access Management
• Firewall Configuration
Network Monitoring System
Monitoring infrastruktur jaringan dan server untuk memastikan layanan tetap stabil dan aman.

Activities:
• Active Alerts Monitoring
• Server Health Monitoring
• Network Traffic Analysis
• Web Service Monitoring
• Top Talkers Detection
• Log Analysis
• Service Status Tracking

Competencies:
• Network Monitoring
• Infrastructure Monitoring
• Incident Detection
• Log Analysis
• Service Monitoring
• Basic Troubleshooting
