  • Membangun sistem hotspot autentikasi dengan captive portal

  • Deploy server cloud pada AWS EC2 dengan Elastic IP
  • Konfigurasi MariaDB sebagai database server
  • Instalasi dan konfigurasi WordPress di atas Nginx
